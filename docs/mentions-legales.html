Lorsque vous remplissez un formulaire, nous recueillons les informations nécessaires pour traiter votre demande : nom, téléphone, e-mail (facultatif), ville, type de client, service souhaité, montant de facture, message et, si vous le souhaitez, une photo de votre facture.
